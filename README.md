# Cafeteria Menu

A small interactive Python program that prints the cafeteria menu and shows the
discounted special for a weekday.

## Run

```powershell
python cafeteria.py
```

Enter a weekday from Monday through Friday when prompted. Other days have no
special.

## Test

Run the test suite with Python's standard-library `unittest` runner:

```powershell
python -m unittest -v
```
